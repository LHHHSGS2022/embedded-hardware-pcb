# Hardware Schematic & PCB Circuit Design

[![Altium Designer](https://img.shields.io/badge/Tools-Altium_Designer-blue?style=flat-square&logo=altium-designer)](https://www.altium.com/)
[![Hardware](https://img.shields.io/badge/Domain-Embedded_Electronics-orange?style=flat-square)](#)

This repository contains schematic designs (`.SchDoc`) and printed circuit board (PCB) layouts (`.PcbDoc`) developed using **Altium Designer** for embedded systems and IoT hardware prototyping.

---

## Key Highlights

- **Schematic Capture (`Sheet1.SchDoc`):** Designed circuit logic, power routing, and signal connections for microcontroller interfaces.
- **PCB Layout (`PCB1.PcbDoc`):** Performed component placement, trace routing, layer stack-up, and design rule check (DRC) for hardware production.
- **Hardware Integration:** Connects physical sensing units and edge processing hardware to support IoT deployment.
