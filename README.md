#  Hardware Schematic & PCB Circuit Design

[![Altium Designer](https://img.shields.io/badge/Tools-Altium_Designer-blue?style=flat-square&logo=altium-designer)](https://www.altium.com/)
[![Hardware](https://img.shields.io/badge/Domain-Embedded_Electronics-orange?style=flat-square)](#)

This repository archives hardware design files, schematic diagrams, and printed circuit board (PCB) layouts developed using **Altium Designer** for embedded systems and hardware prototyping.

---

##  Key Technical Highlights

- **Schematic Capture (`Sheet1.SchDoc`):** Designed circuit block diagrams, pin mapping, power management lines, and component interconnections.
- **PCB Layout & Routing (`PCB1.PcbDoc`):** Performed component placement, trace routing, layer stack-up configuration, and Design Rule Checks (DRC) for physical PCB fabrication.
- **Project Structure (`learning_altium.PrjPcb`):** Integrated hardware compilation structure linking logical schematics with physical PCB footprints.
